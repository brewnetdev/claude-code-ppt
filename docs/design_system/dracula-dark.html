드라큘라 다크 테마 디자인 시스템

Dracula 공식 팔레트(draculatheme.com) 기반의 다크 우선 개발자 디자인 시스템입니다. 무채색 다크 베이스에 액센트는 Purple 한 색만 사용하고, 6색 팔레트는 코드 신택스 하이라이팅 전용으로 격리합니다.

핵심 요약 (TL;DR)

  • UI 크롬 = 무채색 베이스 + 액센트 1색(#bd93f9). 6색은 코드 블록 전용.
  • 그라데이션·글로우·글래스모피즘·모션 장식 전면 금지. 구획은 1px border + 여백.
  • 서체는 IBM Plex Sans KR(본문) + JetBrains Mono(코드·데이터).
  • 토큰은 COLOR.json에서 가져가고, 스펙은 DESIGN-SYSTEM.md 참조.

Do / Don't

Do

  • 다크 무채색 위에 여백과 1px 라인으로 구조를 만든다.
  • 색은 상태(에러/성공)와 단일 액센트, 코드 신택스에만.
  • transition은 색·투명도만, 150ms 이하.

Don't

  • 그라데이션, 글로우 카드, 글래스모피즘.
  • hover 확대·이동, 로드 페이드 스태거.
  • 정보 없는 배경 그래픽, 이모지 불릿.
